¿Qué es una variable en programación?

Una variable es un espacio de memoria reservado para almacenar datos que pueden ser modificados durante la ejecución de un programa. Las variables actúan como contenedores simbólicos que permiten acceder, manipular y reutilizar información de manera eficiente

Existen varios tipos de variables

Entero (int)

Una variable int es una variable que guarda un número entero, o sea, un número sin decimales.
Ademas,Sirven para sumar, restar, multiplicar, dividir, contar cosas, hacer cálculos, etc.
➡️ Ejemplo: -3, 100, 5

Ver ejemplo

Flotantes (float)

Una variable de tipo float ("floating point")
Es una variable numérica que puede guardar números con decimales.
➡️ Ejemplo: 1.75 , -3.14 , 0.0

Ver ejemplo

Cadenas de texto (str)

Una cadena de texto, o string (str),
Es como una caja que guarda letras, números escritos como texto, símbolos, espacios, y más.
➡️ Ejemplo: "Hola" '123' "@Python"

Ver ejemplo

Booleanos (bool)

Es un Tipo de variable que solo tiene dos valores posibles: True ( Verdadero ) o False ( falso ).
➡️ Se usa para decisiones y condiciones. etc.

Ver ejemplo

Listas (list)

Una lista es una colección de elementos.
Sirve para guardar muchos datos juntos en una sola variable.
➡️ Puedes guardar Números , Textos , Booleanos o una combinación de todo.

Ver ejemplo

Tuplas (tuple)

Colección ordenada e inmutable de elementos.
➡️ No se pueden modificar después de crearse.

Ver ejemplo

Diccionarios (dict)

Es una estructura que almacena datos en pares clave: valor.
Cada clave está asociada a un valor y puedes acceder a ellos usando la clave.
Es ideal para guardar información organizada y relacionada como Nombre , edad , ciudad , Etc

Ver ejemplo

Conjuntos (set)

Un conjunto en Python es una colección desordenada, que no permite elementos repetidos.
Se usa para agrupar valores únicos y hacer operaciones como uniones , diferencias o intersecciones .
